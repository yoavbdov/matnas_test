============================================================
  CHESS NIMBUS — PROJECT FILES GUIDE
  A short explanation of every file and why it exists
============================================================

This is a Chess School Management System built with:
  Next.js (App Router) + React 19 + Tailwind CSS + Firebase (Auth + Firestore)
  UI library: shadcn/ui   Language: TypeScript (.tsx)   Direction: RTL / Hebrew

  ROOT CONFIGURATION FILES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

package.json
  Project manifest. Lists all npm dependencies (Next.js, React, Firebase,
  Tailwind, shadcn, etc.) and the scripts: dev, build, start.

tsconfig.json
  TypeScript compiler settings. Sets strict mode and defines the path alias
  @/* → ./src/* so imports look like "@/components/..." instead of "../../../".

next.config.ts
  Next.js build configuration. Currently disables Turbopack and uses Webpack.

eslint.config.mjs
  ESLint rules for code quality and catching common mistakes.

postcss.config.mjs
  PostCSS config needed by Tailwind CSS to process utility classes.

components.json
  shadcn/ui configuration. Tells the shadcn CLI where to put new components,
  which base color to use, and how to resolve imports.

.env.local  (git-ignored)
  Firebase secrets (API key, project ID, etc.). Copy from .env.local.example
  and fill in from the Firebase Console. Never commit this file.

.env.local.example
  Template showing which environment variables are required for Firebase.

next-env.d.ts  (auto-generated)
  TypeScript declarations for Next.js built-in types. Do not edit manually.

  src/app/  — PAGES (Next.js App Router)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

layout.tsx
  Root layout that wraps every page. Sets up RTL direction, loads the global
  font, and wraps everything in the three providers: AuthProvider,
  DataProvider, and ToastProvider.

globals.css
  Global CSS resets and Tailwind base styles applied to the whole app.

page.tsx
  The "/" route. Just redirects the user to /dashboard.

dashboard/page.tsx
  Main overview page. Shows stat cards (total students, active classes, etc.),
  today's sessions, enrollment status per class, and a rating distribution chart.

students/page.tsx
  Manages all students. Includes the students table, toolbar (search + filter),
  add/edit modal, detail modal, availability checker, and CSV import/export.

teachers/page.tsx
  Manages all teachers. Same pattern as students: table + toolbar + modals +
  CSV import/export.

classes/page.tsx
  Manages all classes. Shows class list with enrollment counts, lets you
  add/edit classes, manage schedule slots, assign resources, and enroll students.

attendance/page.tsx
  Attendance tracking. Three-panel layout: pick a class on the left, see past
  sessions in the middle, and fill in today's attendance on the right.

rooms/page.tsx
  Manages rooms and physical equipment in two tabs. Supports availability
  checking, CSV import/export, and add/edit modals for both.

schedule/page.tsx
  Weekly calendar view showing all classes, tournaments, and events. Includes
  conflict detection and filter controls.

tournaments/page.tsx
  Manages tournaments and one-time/recurring events in two tabs. Handles
  participants, rounds, and equipment assignments.

league-groups/page.tsx
  Manages league groups split into three categories (Adults / Youth / Women).
  Players can be assigned to groups from the student list.

login/page.tsx
  Email + password login form backed by Firebase Authentication.

settings/page.tsx
  Settings page (minimal — placeholder for future configuration options).

api/sync-chess-ratings/route.ts
  Next.js API route (server-side). Fetches updated ratings from the Israeli
  Chess Federation and FIDE, then writes them back to Firestore.

  src/context/  — REACT CONTEXT PROVIDERS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

AuthContext.tsx
  Provides the current Firebase Auth user (or null) to the whole app.
  Any component can call useAuth() to know who is logged in.

DataContext.tsx
  Provides all Firestore collections as live arrays (students, teachers,
  classes, rooms, etc.) to the whole app. Uses useCollection hooks internally
  so data updates in real-time without manual fetching.

ToastContext.tsx
  Provides a showToast(message, type) function to the whole app, backed by
  the Sonner notification library. Any component can trigger a toast without
  prop-drilling.

  src/firebase/  — ALL FIREBASE CODE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

firebase.ts
  Initializes the Firebase app from env variables and exports the two
  singletons: auth (Firebase Auth) and db (Firestore database).

firestore.ts
  Generic Firestore CRUD helpers: addDocument, updateDocument, deleteDocument.
  All pages that write data call these functions — never the Firestore SDK directly.

hooks/useAuth.ts
  React hook that listens to Firebase Auth state changes and returns the
  current user. Used by AuthContext.

hooks/useCollection.ts
  React hook that subscribes to a Firestore collection in real-time. Returns
  an array of documents that auto-updates when Firestore changes. Used by DataContext.

hooks/useDocument.ts
  Like useCollection but for a single Firestore document. Returns one object
  that updates in real-time.

hooks/useAttendance.ts
  Specialized hook that fetches attendance sessions for a given class and
  sorts them newest-first. Used by the attendance page.

hooks/useRatingThresholds.ts
  Fetches the customizable chess rating tier thresholds from Firestore. Used by
  the dashboard's rating distribution chart.

utils.ts
  Single export: the cn() helper that merges Tailwind class strings (from
  shadcn). Used by nearly every UI component.

utils/utils.ts
  General utility functions used across the app:
    - formatPhone()    formats "0532422215" → "053-2422215"
    - calcAge()        computes age from a birth date string
    - timeToMinutes()  converts "HH:MM" to an integer for comparisons

config/config.ts
  App-wide numeric limits and defaults used in forms and validation
  (e.g. MAX_STRING_LENGTH, MAX_AGE, MAX_INT_INPUT).

config/constants.ts
  Static lookup tables used throughout the UI:
  day names, color options, recurrence options, chess titles, grade labels.

helpers/studentHelpers.ts
  Derives a student's status (active / league-only / inactive) by checking
  whether they have any active class enrollments or tournament registrations.

helpers/teacherHelpers.ts
  Derives a teacher's status (active / inactive) by checking whether they
  are currently teaching any class.

schedule/scheduleHelpers.ts
  Pure functions for recurring schedule logic: given a ScheduleSlot and a
  date, decide whether the slot occurs on that date. Handles weekly, biweekly,
  etc. recurrence patterns.

schedule/classHelpers.ts
  Additional helpers specific to classes (e.g. building a flat list of all
  occurrences within a date range).

validation/validators.ts
  The single source of truth for form validation:
    - LIMITS object (max lengths for every field type)
    - VALIDATION_ERRORS object (all Hebrew error message strings)
    - Helper functions: validatePhone(), digitsOnly(), etc.

validation/validators.test.ts
  Unit tests for the validator functions.

availability/studentAvailability.ts
  Pure function that, given a time slot and the full students + classes data,
  returns which students are free and which are busy.

availability/teacherAvailability.ts
  Same as above but for teachers.

availability/roomAvailability.ts
  Same as above but for rooms.

chess/chessSync.ts
  Logic for calling the Israeli Chess Federation API and FIDE to pull updated
  ratings for each player. Called by the sync-chess-ratings API route.

conflicts/tournamentHelpers.ts
  Detects scheduling conflicts within tournament rounds (two rounds at the
  same time in the same room, etc.).

conflicts/eventHelpers.ts
  Detects scheduling conflicts for events (overlapping event times).

conflicts/crossConflictHelpers.ts
  Detects conflicts between different entity types — e.g. a class slot that
  overlaps with a tournament round in the same room.
